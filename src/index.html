Data Sources

Where MSR researchers obtain data. Each source lists the kind of data it provides and a brief description.

Source Data Provided Description
GitHub Repositories, commits, pull requests, issues, stars Large-scale hosting platform for open-source software; the richest single source of development activity.
Stack Overflow Questions, answers, tags, user reputation Q&A site for programmers; useful for studying knowledge sharing, problem types, and community dynamics.
JIRA Issue tracking, sprint data, bug reports Project management and issue-tracking tool used in industry; supports study of defect and workflow data.
App Stores Google Play and Apple App Store reviews, ratings, downloads Mobile app marketplaces; valuable for studying user feedback, sentiment, and release impact.
Travis CI / Jenkins Build logs, test results, deployment data Continuous integration services; provide evidence of build success, failures, and testing practice.
Mailing Lists Developer discussions, archives Long-running project communication archives; useful for studying design decisions and governance.
npm Registry Package dependencies, downloads, versions JavaScript package registry; supports study of dependency networks, ecosystem health, and versioning.
