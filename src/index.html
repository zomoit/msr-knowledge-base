Data Sources

Where we get data from.

SourceData TypeDescription
GitHub Repositories, commits, pull requests, issues, stars The largest code-hosting platform, offering rich history of open-source development activity.
Stack Overflow Questions, answers, tags, user reputation A Q&A site where developers ask and answer programming questions, useful for studying developer needs and knowledge sharing.
JIRA Issue tracking, sprint data, bug reports A project-management tool whose public instances expose bug reports and sprint data for many projects.
App Stores Google Play and Apple App Store reviews, ratings, downloads Marketplaces where users review mobile apps, giving direct feedback on software quality and features.
Travis CI / Jenkins Build logs, test results, deployment data Continuous integration services that record how software is built, tested, and deployed.
Mailing Lists Developer discussions, archives Archived email conversations in which developers discuss design, patches, and project decisions.
npm Registry Package dependencies, downloads, versions The package registry for JavaScript, used to study dependency networks and release practices.
